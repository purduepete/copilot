# Session handoffs

Notes for moving agent work between machines, for example laptop to Dev Box.
The `session-handoff` skill writes and reads them.

## Naming

`yyyy-MM-dd-HHmm-<repo>-<topic>.md`, local time, lowercase hyphenated words.
Example: `2026-10-29-1150-fde-revenue-bedrock-session-sync.md`.

## Content rules

This repo is private on personal GitHub. Notes describe the work only:

- Allowed: repo, branch, commit, file paths, goal, steps done and next, decisions.
- Not allowed: secrets, tokens, connection strings, customer or financial data,
  pasted query results, or confidential document text.

Code and data stay in their own repos and systems. Push them before handing off.
